# Dried Mango Vector Label Print Specs

Files:

- `Dried Mango - Front Label VECTOR.svg`
- `Dried Mango - Back Label VECTOR.svg`

Format:

- True SVG vector artwork.
- No embedded raster images.
- Editable text, shapes, icons, barcode-style marks, mango artwork, and layout paths.
- Finished trim size: `100mm x 150mm`.
- Document size with bleed: `106mm x 156mm`.
- Bleed: `3mm` on all sides.
- Safe area: `4mm` inside trim.

Print Guide Colors:

- Blue dashed rectangle: trim/cut line.
- Pink dashed rectangle: safe area.
- Remove or hide guide layers before final production if the print shop requires artwork only.

Use:

- Suitable for pouch labels, jar labels, bottle labels, carton stickers, and resized packaging applications.
- Keep the aspect ratio when scaling unless the printer requests a custom wrap label size.
- For curved bottles, ask the printer for the required label width, height, corner radius, and bleed; then resize the SVG artboard and preserve the safe area.
